# CDT504 Revision Self-Test

Open <https://bicheng.github.io/cdt504/> to run the self-test in the browser.

## What is here

- `index.html` - the self-contained test page (no network needed after load).
- `GLOSSARY.md` - glossary: every courseware term in English and Chinese, with the slide
  it comes from, plus English -> Chinese and Chinese -> English quick indexes.
- `CONCEPTS.md` - concept table: every named exam point of Lessons 1-7 in English and
  Chinese, with its source slide and the questions that cover it.
- `CDT504_Exam_Bank.md` - all 245 questions with answers, explanations and source slides.
- `COVERAGE.md` - knowledge point coverage check: the same mapping in table form.

## Test modes

- **Practice** - browse all questions and open the answer and explanation on demand.
- **Lesson test** - 35 questions from one lesson, timed, with instant feedback when a
  single-choice answer is wrong (the card shakes and flashes red).
- **Random draw** - 35 questions drawn at random, timed, same instant feedback.
- **Exam** - everything, timed, answers stay hidden until you submit.

A glossary search box is built into the page ("术语速查" in the toolbar).

Scope: Lessons 1-7, 35 questions each, 245 in total - the range of the class quiz.
Every question cites the courseware slide it comes from. The only source is
`lectures/CDT504` in the course archive; terminology follows the slides.
